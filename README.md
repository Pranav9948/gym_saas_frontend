# GymFlow — Gym Management SaaS

A multi-tenant gym management platform built to simplify gym operations, membership management, attendance, billing and business analytics.

**Live Demo:** https://gym-saas.com

**Interactive Demo:** https://app.supademo.com/demo/cmv6wiajd02zwqmuq9g0on80n

## Features

- Multi-tenant gym management
- Role-based dashboards and access control
- Member and trainer management
- Attendance tracking
- Subscription and billing management
- Revenue and membership analytics
- Super-admin platform management
- Responsive dashboard interface

## Frontend Technology Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Zustand
- TanStack Query
- React Hook Form
- Zod
- shadcn/ui

## Project Structure

- `app/` — Application routes and pages
- `components/` — Reusable UI components
- `services/` — API service integrations
- `hooks/` — Custom React hooks
- `store/` — Client-side state management
- `schemas/` — Validation schemas
- `types/` — TypeScript definitions

## Getting Started

### Prerequisites

- Node.js
- pnpm

### Installation

```bash
git clone https://github.com/Pranav9948/gym_saas_frontend.git
cd gym_saas_frontend
pnpm install
```

Configure the required environment variables using the provided `example-env` file.

### Run locally

```bash
pnpm dev
```

Open http://localhost:3000.
